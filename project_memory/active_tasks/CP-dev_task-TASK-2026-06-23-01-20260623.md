### Implementation outline (Cursor)

1. **New package** `integrations/wallet_editor_registry_db/`:
   - `schema.sql` or Alembic migration
   - `mirror.py` — `mirror_append_run()`, `mirror_patch_enable()`, `mirror_refresh_rows()`
   - `import_cli.py` — one-time Excel → DB
   - `reconcile.py` — compare fingerprints counts/hashes
   - `connection.py` — lazy connect; no import-time fail if flag off

2. **Hooks** (minimal, **I-REG-08**):
   - `wallet_editor_registry.py`: **only** after `_AppendOutcome.SUCCESS` (upload completed + `mark_run_processed`) and `_PatchOutcome.SUCCESS` — **not** on TRANSIENT/REV_CONFLICT/TIMEOUT/PERMANENT
   - `wallet_editor_registry_refresh.py`: **only** after `_RefreshOutcome.SUCCESS` (upload completed)
   - `_AppendOutcome.DUPLICATE`: mirror optional idempotent no-op only if Excel row already present; **never** write to Postgres if Excel upload did not succeed in this attempt
   - Wrap in `if mirror_enabled(): schedule_mirror(...)` — daemon thread, try/except log; mirror function receives data **after** Excel commit confirmed

3. **Health**: extend `RegistryHealthReport` + `format_registry_health_report` with mirror fields

4. **Tests**: flag off = no DB calls (mock); idempotent upsert; mirror failure doesn't fail append

### Forbidden (reiterate)

- No read path changes
- No eligibility/lifecycle changes
- No hold/otlezka tables Phase 1
- No outbox semantics change
