## Workflow (справка)

| Статус | Действие |
|--------|----------|
| `draft` | Заполнены Goal, Business Context, черновик Desired |
| `ready` | Заполнены все поля; при medium+ risk — есть `_impact.md` |
| `in_progress` | Реализация (вне этого шаблона) |
| `done` | Success Criteria выполнены; при необходимости — `_review.md` approve |
| `cancelled` | Причина в заметках |
