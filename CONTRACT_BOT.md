### 1. Назначение документа

### 2. Этот документ фиксирует контракт поведения Telegram-бота, который управляет правилами в rules.xlsx.

     
### Цели бота:

* убрать ручное редактирование Excel из операционной работы

* гарантировать корректность правил
* исключить конфликты (2 active rules)

* обеспечить аудит и воспроизводимость

#### Бот — единственная рекомендованная точка изменения правил.

### 2. Общие принципы работы бота

### 2.1 Источник истины

* rules.xlsx — единственный источник правил

* бот не хранит состояние

* каждое действие начинается с загрузки актуального файла

### 2.2 Атомарность

Любая операция:

- либо применяется полностью

- либо не применяется вообще

#### Частичные изменения запрещены.

### 2.3 Fail-safe политика

Если обнаружено:

- нарушение контракта

- конфликт активных правил

- ошибка парсинга данных

#### 👉 бот НЕ сохраняет файл и возвращает ошибку пользователю.

### 2.4 Управление enabled

#### пользователь никогда не управляет enabled напрямую

бот сам:

- выключает старое активное правило

- включает новое

#### это часть контракта

### 3. События (audit)

Для каждой операции бот обязан писать события:

#### Обязательные типы

- rule_change_requested

- rule_change_applied

- rule_change_failed

#### Минимальные поля события

- rule_type

- action

- actor

- rules_version_before

- rules_version_after (если применено)

- details

- error (если failed)
